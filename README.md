# AI-Generated and Human Face Emotion Recognition

This blinded repository contains the deidentified data, analysis code, tables,
figures, and supporting documentation for a study comparing emotion recognition
from established human-face photographs and AI-generated face images.

## Reproduce the analysis

Run the two scripts from any working directory. Script 1 validates the released
CSV, rescoring the questionnaires and reconstructing the trial-level data.
Script 2 fits the models and regenerates all tables, figures, diagnostics, and
provenance files.

```bash
Rscript R/01_prepare_data.R
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  Rscript R/02_run_analyses.R
```

The thread limits make numerical output stable across common BLAS
implementations. The scripts stop with an error if the released schema, trial
counts, score calculations, or key analysis checks do not match expectations.

Package versions are recorded in `renv.lock`. To recreate the package library:

```r
install.packages("renv")
renv::restore()
```

## Repository contents

- `data/ai_faces_study.csv`: the single analysis release, with one row per
  participant and repeated trial slots in columns.
- `data/stimulus_manifest.csv`: synthetic stimulus IDs and analysis metadata.
- `data/data_dictionary.csv`: variable-level definitions for the wide CSV.
- `R/01_prepare_data.R`: transparent validation, scoring, and reshaping.
- `R/02_run_analyses.R`: descriptive analyses, models, tables, and figures.
- `derived/`: analysis-ready files generated by Script 1.
- `results/`: complete generated output from both scripts.
- `manuscript_figures/`: non-generated task, stimulus-example, and composite
  figures used by the manuscript.
- `docs/`: methods, equations, data notes, and a result crosswalk.
- `task/stimulus_sampling.mjs`: isolated reference implementation of the
  experimental stimulus-sampling procedure.
- `analysis_decisions.csv`: fixed analysis settings and unresolved confirmatory
  decisions.

## Data structure

`data/ai_faces_study.csv` contains 1,277 rows and 901 columns. It includes
participant-level grouped demographics, eight retained questionnaire totals and
their 79 component items, and up to 80 emotion-recognition trials per person.
Each trial has ten consistently named fields, for example
`trial_001_target_emotion`, `trial_001_correct`, and `trial_001_rt_sec`.
Blank trial slots represent trials that were not observed.

Participant and stimulus identifiers are synthetic and cannot be linked using
this repository. Direct identifiers, collection-platform identifiers, dates,
free text, source filenames, and original linkage keys are not included.

## Important interpretation points

The fitted trial strata are mutually exclusive: FACES, AI-white, and
AI-non-white. The reported AI-diverse estimate is then pooled from all AI trials,
so AI-white remains a subset of AI-diverse without duplicating observations in
the mixed models.

The package is a reproducible observational analysis, not evidence of diagnostic
validity, non-inferiority, or interchangeability. A confirmatory clinical-outcome
family and non-inferiority margin were not specified.

The established FACES photographs are not redistributed here. The stimulus
manifest is sufficient to reproduce every reported analysis because the models
use released synthetic stimulus IDs and coded stimulus attributes. See
`docs/stimulus_materials.md` for image-generation and availability details.
